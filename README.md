# 🚀 Tecnologias de Desenvolvimento

Neste curso, vamos aprender a desenvolver aplicações utilizando duas tecnologias importantes: **Dart e Flutter**.

## 💙 1. Dart

Dart é uma linguagem de programação desenvolvida pelo Google. É uma linguagem moderna, multiplataforma e de fácil aprendizagem, utilizada principalmente no desenvolvimento de aplicações.

Com Dart, podemos aprender conceitos fundamentais da programação, como:

- Variáveis e tipos de dados;
- Estruturas condicionais;
- Estruturas de repetição;
- Funções e métodos;
- Classes e objetos;
- Programação Orientada a Objetos (POO).

📚 **Material oficial para estudo:**

🔗 [Acesse a documentação oficial do Dart](https://dart.dev/)

## 💙 2. Flutter

Flutter é um framework de desenvolvimento criado pelo Google que permite construir aplicações para diferentes plataformas utilizando uma única base de código.

Com Flutter, podemos desenvolver aplicativos para:

- 📱 Android;
- 🍎 iOS;
- 🌐 Web;
- 💻 Windows, Linux e macOS.

Utilizando a linguagem Dart, o Flutter permite criar interfaces modernas, interativas e personalizadas.

Durante nossos estudos, vamos aprender a trabalhar com:

- Widgets;
- Textos, imagens e ícones;
- Botões e campos de formulário;
- Containers e organização de layouts;
- Navegação entre telas;
- Gerenciamento de estados;
- Desenvolvimento de aplicativos completos.

📚 **Materiais oficiais para estudo:**

🔗 [Documentação e recursos de aprendizagem do Flutter](https://docs.flutter.dev/reference/learning-resources)

## 🎯 Nosso objetivo

Ao longo das aulas, vamos transformar conhecimentos teóricos em aplicações práticas, desenvolvendo habilidades de programação, raciocínio lógico, criatividade e resolução de problemas.

**Lembre-se: todo grande desenvolvedor começou aprendendo o básico. Pratique, pesquise, erre, corrija e continue evoluindo!** 💻🚀
